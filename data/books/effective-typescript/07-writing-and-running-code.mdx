타입스크립트로 코드를 작성해도 실행되는 것은 자바스크립트다. 타입으로만 존재하는 문법인지, 실행할 코드를 생성하는 문법인지 구분하면 동작을 이해하기 쉽다.

## ECMAScript 기능 먼저 살펴보기

타입스크립트 전용 기능을 선택하기 전에 자바스크립트의 표준 기능으로 표현할 수 있는지 확인한다.

`enum`은 런타임 객체를 생성하는 문법이다. 단순한 값의 집합이라면 객체와 `as const`, 또는 문자열 리터럴 유니온으로 표현할 수도 있다.

```typescript
const OrderStatus = {
  pending: 'pending',
  completed: 'completed',
} as const

type OrderStatus = (typeof OrderStatus)[keyof typeof OrderStatus]
```

`const enum`은 일반적인 컴파일 설정에서 사용 위치에 값이 인라인되고 선언이 제거된다. 다만 출력 방식은 설정에 따라 달라질 수 있고, 패키지 경계를 넘어서 사용할 때 주의할 점이 있다.

객체로 표현하는 방법과 `const enum`의 제약은 [공식 문서](https://www.typescriptlang.org/docs/handbook/enums.html#objects-vs-enums)에 설명돼 있다. 어떤 기능이 필요한지, 생성된 코드가 어떻게 사용되는지 보고 선택한다.

## 객체를 순회할 때의 타입

키와 값을 함께 순회할 때는 `Object.entries()`를 사용할 수 있다.

```typescript
const counts: Record<string, number> = { pending: 2, completed: 5 }

for (const [status, count] of Object.entries(counts)) {
  console.log(status, count) // status: string, count: number
}
```

`Object.entries()`가 항상 객체 타입의 키와 값 사이의 정확한 관계를 보존하는 것은 아니다. 객체의 타입 형태에 따라 키는 `string`, 값은 `any` 등으로 추론될 수도 있다.

객체 타입에 선언된 속성이 런타임 객체의 모든 속성을 뜻하는 것도 아니다. 타입스크립트의 구조적 타이핑에서는 추가 속성이 있는 값을 더 좁은 객체 타입으로 전달할 수 있다.

`for...in`은 상속된 열거 가능한 속성까지 순회할 수 있다. `Object.entries()`는 객체 자신의 열거 가능한 문자열 키 속성을 다룬다. 어떤 속성을 순회하려는지에 맞춰 선택한다. ([MDN 문서](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/entries))

## private과 런타임 비공개 필드

타입스크립트의 `private`는 타입 검사 단계에서 접근을 제한한다. 자바스크립트로 변환할 때 이 접근 제어자는 제거되므로 실행 시점의 비공개를 보장하지 않는다.

자바스크립트에는 `#`으로 시작하는 비공개 필드가 있다. 이 필드는 실행 시점에도 클래스 외부의 접근을 제한한다.

```typescript
class Counter {
  #value = 0

  increment(): number {
    this.#value += 1
    return this.#value
  }
}
```

`private`와 `#`의 차이는 [TypeScript 공식 문서](https://www.typescriptlang.org/docs/handbook/2/classes.html#caveats)에 정리돼 있다.

클로저로 값을 감추는 방법도 있다. 중요한 것은 타입 검사에서 접근을 막는 것과 런타임에서 실제로 감추는 것을 구분하는 일이다.
