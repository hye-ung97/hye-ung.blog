기존 자바스크립트 코드에 타입을 추가하기 전에 코드의 의도를 분명하게 만들면 마이그레이션도 쉬워진다. 이 장에서는 모던 자바스크립트로 정리하는 항목을 메모했다.

## 변수 선언과 클래스

`var` 대신 `let`과 `const`를 사용하면 블록 스코프를 기준으로 변수의 범위를 파악할 수 있다. 값을 다시 할당할 필요가 없다면 `const`로 선언한다.

생성자 함수와 프로토타입으로 작성한 코드에서는 클래스 문법을 사용할 수 있는지 살펴본다. 기존 동작을 유지하는지 확인하면서 의도가 드러나도록 정리한다.

타입스크립트 컴파일러를 자바스크립트의 변환 도구로 사용할 수도 있다. `allowJs`로 자바스크립트 파일을 포함하고, `target`으로 출력할 자바스크립트 버전을 정하는 방식이다. ([설정 문서](https://www.typescriptlang.org/tsconfig/#allowJs))

## 반복문은 필요한 정보에 맞춰 선택하기

값만 필요한 반복에는 `for...of`를 사용할 수 있다. 인덱스를 직접 관리할 필요가 줄어든다.

```javascript
const chapterTitles = ['타입 시스템', '타입 추론', '타입 설계']

for (const title of chapterTitles) {
  console.log(title)
}
```

인덱스도 필요하면 `forEach()`의 두 번째 매개변수나 배열의 `entries()`를 사용할 수 있다. 중간에 반복을 끝내야 하는지, 비동기 작업을 순서대로 기다려야 하는지 등 필요한 동작을 보고 선택한다.

## 화살표 함수와 기본 매개변수

짧은 콜백은 화살표 함수로 간결하게 표현할 수 있다. 다만 화살표 함수는 자신의 `this`를 만들지 않으므로, 기존 함수의 `this` 사용 방식도 확인해야 한다.

기본값은 매개변수에 직접 선언할 수 있다.

```javascript
function parseAmount(text, radix = 10) {
  return parseInt(text, radix)
}
```

기본값을 직접 적으면 호출할 때 해당 인수를 생략할 수 있다는 점이 분명해진다. 이 예제에서 변환할 수 없는 문자열은 `NaN`을 반환하므로, 실제 입력을 받을 때는 결과를 검사하는 처리도 필요하다.
